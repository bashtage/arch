=========
Version 9
=========

Release 9.0 (Unreleased)
========================
- Fixed :class:`~arch.bootstrap.SPA` and :class:`~arch.bootstrap.StepM` so that
  ``studentize=True`` (the default) studentizes the loss differentials. In
  previous versions the option had no effect on the results. The loss
  differentials are now studentized in the original data and inside each
  bootstrap replication, using the standard error from a kernel long-run
  variance estimator that matches the bootstrap, or from a nested bootstrap
  if ``nested=True``. P-values, critical values and the superior models differ
  from previous versions when using the default arguments.
- ``nested=True`` in :class:`~arch.bootstrap.SPA` and
  :class:`~arch.bootstrap.StepM` now computes the variances used to studentize
  in every bootstrap replication using a nested bootstrap, and not only in the
  original data, and never uses the kernel estimator. ``nested=True`` requires
  ``studentize=True`` and raises a ``ValueError`` otherwise.
- When ``nested=False``, the long-run variances in
  :class:`~arch.bootstrap.SPA` and :class:`~arch.bootstrap.StepM`, which are
  used to select the models that are re-centered when computing the consistent
  p-value, now use the kernel that matches the bootstrap. Previously they
  always used the stationary bootstrap kernel, so the consistent p-value can
  also change with ``studentize=False`` when using the circular or moving
  block bootstraps.
- Fixed :func:`~arch.unitroot.auto_bandwidth` so that the autocovariances are
  not truncated to integers. In previous versions any series with
  non-integer values could return an incorrect bandwidth or raise
  ``ZeroDivisionError``.
- Added :class:`~arch.covariance.var.PreWhitenedRecolored`, which
  implements the VAR-HAC (den Haan and Levin) and pre-whitened recolored
  (Andrews and Monahan) long-run covariance estimators, and the
  :class:`~arch.covariance.kernel.ZeroLag` kernel that it uses for VAR-HAC.
  The order, residuals and residual covariance of the VAR are available
  as ``order``, ``resid`` and ``resid_cov``.
- Kernel names are now looked up in one place,
  :func:`arch.covariance.kernel.get_kernel_estimator`, using the canonical
  list ``arch.covariance.kernel.KERNELS``. All estimators that take a
  ``kernel`` accept the same names, in any case and with hyphens or
  underscores ignored, and raise the same error, which lists the available
  kernels, for an unknown name.
